belajar clone Tambahkan collaborator di GitHub melalui Settings → Collaborators. Accept invite melalui email/inbox GitHub. Buka VS Code dan Terminal. Clone repository dengan git clone https://github.com/username/repository.git. Masuk ke directory repository dengan cd repository. Buat branch baru dengan git branch nama_branch_anda. Pindah ke branch dengan git checkout nama_branch_anda. Buat perubahan pada file, misalnya menambahkan nama_anda.html. Jalankan git add Jalankan git commit -m "Menambahkan file nama_anda.html". Push branch dengan git push -u origin nama_branch_anda. Buka repository di GitHub, masuk ke menu Pull requests, lalu buat Pull Request. Setelah disetujui, lakukan Accept/Merge Pull Request. Jika sudah selesai, buka kembali repository di GitHub dan lihat perubahan yang sudah dibuat.
